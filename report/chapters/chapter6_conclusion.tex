\section{Conclusion}
\label{chap:conclusion}

This thesis investigated parameter-efficient domain adaptation of the AutoBrep generative CAD model \cite{Xu2025autobrep} using Low-Rank Adaptation (LoRA) \cite{Hu2021lora}, focusing on three research questions. Through systematic experimentation we find that:

\begin{enumerate}
	\item \textbf{AutoBrep's base capabilities} far exceed prior diffusion-based methods (Chapter~\ref{chap:results}), producing watertight, topologically complex solids with up to 100+ faces in a single autoregressive pass.
	
	\item \textbf{LoRA enables rapid, data-light adaptation} to specialized domains (cylinders, cuboids with holes) using only $\approx$1\% additional parameters and 600 training samples, achieving $\approx$90\% decodable-solid rate. However, LoRA acts strictly as a \emph{distribution sharpener} (Section~\ref{sec:lora_dynamics}): it can amplify geometric motifs already present in the base model's latent feature space but cannot introduce genuinely novel primitives. Adapter placement and rank beyond $r=16$ yield negligible gains, confirming that the bottleneck lies in the base model's pre-trained geometry coverage, not in adapter capacity.
	
	\item \textbf{Sequence completion tasks fail} across all fine-tuning regimes (Section~\ref{sec:sequence_completion}). Despite the causal transformer architecture, the unconditional pre-training objective left the model unable to infer missing geometry from partial token sequences---an effect that LoRA cannot remedy without explicit conditional training objectives.
\end{enumerate}

\par

In essence, LoRA fine-tuning of AutoBrep solves the practical problem of \emph{style-consistent generation} within a known shape language when the domain's geometric vocabulary already exists in the base model. It does \textbf{not} solve the problem of learning topologies absent from the original training data, nor does it enable (auto)completion without explicit training modifications (see Chapter~\ref{chap:discussion}).
