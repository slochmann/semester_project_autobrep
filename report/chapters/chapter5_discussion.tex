\section{Discussion and Limitations}
\label{chap:discussion}

%===============================================================
\subsection{Key Findings and Insights}
%===============================================================

This work systematically investigates the application of Low-Rank Adaptation (LoRA) for domain-specific fine-tuning of the AutoBrep generative model. The experiments reveal fundamental insights about the capabilities and constraints of parameter-efficient fine-tuning for generative CAD.

\par

\textbf{Central Finding: LoRA as Distribution Sharpener}

As demonstrated in Section~\ref{sec:lora_dynamics}, LoRA functions as a \emph{distribution sharpener} rather than a distribution shifter: it concentrates probability mass onto modes already present in the base model's feature space rather than learning genuinely new geometric features. The fine-tuned model amplified characteristic training features (e.g., cylindrical geometry, hole patterns) without reproducing training shapes exactly, maintaining approximately 90\% decodability throughout.

\textbf{Implications:}
\begin{itemize}
	\item \textbf{Feature Space Constraint}: The base model's learned representations fundamentally limit what LoRA can achieve. New geometric features cannot be learned; only existing modes can be concentrated or emphasized.
	\item \textbf{Data-Efficient Adaptation}: Despite this constraint, LoRA successfully adapted the model to custom domains using only 600 samples, requiring minimal computational resources (single GPU, $\approx$ 0.5 hour training).
\end{itemize}

%===============================================================
\subsection{Model Architecture Constraints}
%===============================================================

Beyond the LoRA-specific limitations, the AutoBrep model architecture itself imposes constraints that affect fine-tuning outcomes.

\par

\textbf{Unconditional Training and Limited Conditional Capabilities:}

The provided AutoBrep checkpoint was trained unconditionally without support for arbitrary conditional generation, as opposed to the papers presentation of autocomplete. The repository code contains geometry tokens that are commented out, indicating these were not included during training. This architectural choice affects:

\begin{itemize}
	\item \textbf{Standard Autoregressive Completion}: The model should support standard sequence completion (given the first $k$ tokens, generate tokens $k+1, k+2, \ldots$) through its causal masking mechanism. However, this capability was not emphasized or validated in the provided checkpoint.
	\item \textbf{Arbitrary Subset Conditioning Fails}: The model cannot condition on arbitrary subsets of tokens presented out of causal order. Attempts to prompt with non-consecutive tokens or arbitrary face/edge subsets resulted in generation that failed to decode.
	\item \textbf{Interdependency Modeling}: Without explicit training on masked prediction or conditional objectives, the model may not optimally capture geometric and topological interdependencies between faces and edges—constraints that could enhance generation quality.
\end{itemize}

\textbf{Tokenization Vocabulary Constraints:}

AutoBrep uses discrete tokenization with Finite Scalar Quantization (FSQ) codebooks of 1000 tokens for surfaces and 1000 for edges. Empirically, surface reconstruction was observed to be 100\% geometrically smooth with no sewing problems within specified tolerances (see Chapter~\ref{chap:methodology}, Table~\ref{tab:reconstruction_tolerances}). However, the limited vocabulary size (2000 tokens for geometry across faces and edges) may constrain the diversity and complexity of representable shapes beyond the training data shapes. The vocabulary may be insufficient to capture specialized feature types outside the base model's training distribution.

%===============================================================
\subsection{Comparison to Alternative Approaches}
%===============================================================
\par

\textbf{Diffusion-Based Methods (BrepGen):}

While BrepGen (Chapter~\ref{chap:background}) offers continuous conditioning through its diffusion-based architecture, published results show it achieves near-zero validity on high-complexity solids (50+ faces). In contrast, AutoBrep maintains approximately 90\% decodability across the full complexity range. This architectural difference motivated selecting AutoBrep as the base model for LoRA fine-tuning on limited datasets (600 samples). 

\textbf{Latent Diffusion (HoLa):}

Hybrid approaches combining latent diffusion with explicit topology encoding represent a promising alternative for future fine-tuning work, potentially combining AutoBrep's stability with better generalization capabilities.

%===============================================================
\subsection{Limitations of LoRA Fine-Tuning}
%===============================================================

While LoRA provides efficient fine-tuning, several fundamental limitations emerged from this work:

\par

\textbf{Feature Space Boundedness:}

LoRA adapters cannot introduce geometrically novel features. Through experimentation on 600-sample datasets:
\begin{itemize}
	\item \textbf{Mode Concentration Only}: Adapters amplified existing modes in the base model's feature space but could not learn features outside this space.
	\item \textbf{Training Data Requirement}: For effective mode amplification, the base model must already contain (in distributed form) representations of the target geometric features.
	\item \textbf{Simple vs. Complex Geometries}: Basic shapes (cylinders, cubes) fine-tuned more effectively, while more complex shapes different from training data showed limited improvement (not easily representable by amplifying existing modes).
\end{itemize}

\textbf{Adapter Placement and Rank Scaling:}

As detailed in Section~\ref{sec:ablation}, rank scaling improved adaptation quality up to a saturation point, above which higher ranks showed negligible benefit. Similarly, adding feed-forward adapters to attention-only configurations provided no meaningful quality improvement, confirming that attention-layer adaptation is the primary mechanism.

\textbf{Temperature-Robustness Trade-off:}

Temperature variation maintained consistent decodability across the tested range (see Section~\ref{sec:ablation}) but could not recover from fundamental distribution mismatch. No temperature setting enabled generation of out-of-distribution features or genuinely novel geometry.

\textbf{Overfitting Sensitivity:}

With only 600 training samples, the model was highly sensitive to learning rate and epoch count (see Section~\ref{sec:ablation} for specifics). Continuous monitoring of the train--validation loss gap was essential; divergence reliably indicated approaching model collapse.

%===============================================================
\subsection{Lessons Learned}
%===============================================================

The fine-tuning process revealed practical insights for practitioners:

\par

\textbf{Best practices:}
\begin{itemize}
	\item \textbf{600 Samples as Baseline}: Successful fine-tuning was achieved with 600 samples per domain, suggesting this scale may be practical minimum for simple geometries.
	\item \textbf{Geometric Diversity}: Simple primitives (cylinders, cubes) fine-tune more reliably than complex irregular geometries.
	\item \textbf{Preprocessing Validation}: Validate STEP file parsing and UV-grid generation before training; corrupted preprocessing cascades into training failures.
\end{itemize}

%===============================================================
\subsection{Future Research Directions}
%===============================================================

The findings of this work suggest several promising directions for advancing generative CAD models:

\par

\textbf{Architectural Improvements to AutoBrep:}

The current AutoBrep checkpoint's limitations point toward specific improvements:
\begin{itemize}
	\item \textbf{Conditional Training}: Retraining or fine-tuning with geometry tokens enabled and masked prediction objectives would enable autocompletion and sequence continuation.
	\item \textbf{Larger Base Models}: The theoretical saturation at ``GPT2/3 scale'' (1B parameters) suggests that larger models (300M--1B) trained on more diverse data would contain richer feature spaces, expanding what LoRA adapters can amplify.
	\item \textbf{Continuous Latent Spaces}: Replacing discrete tokenization with continuous latent representations might reduce quantization error while maintaining generation speed.
\end{itemize}

\textbf{Alternative Fine-Tuning Approaches:}

Given LoRA's mode-concentration constraint, alternative strategies may overcome this limitation:
\begin{itemize}
	\item \textbf{Diffusion-Based Fine-Tuning}: Fine-tuning BrepGen or HoLa on custom domains might enable learning novel features, as diffusion models have shown better generalization on out-of-distribution tasks.
	\item \textbf{Flow Matching for BrepGen}: Replacing the diffusion models in BrepGen with flow matching, as suggested in preliminary explorations, could improve efficiency while maintaining conditional generation capability.
	\item \textbf{Hybrid Models}: Combining autoregressive generation (for speed) with diffusion-based refinement (for quality) could balance practical deployment with output fidelity.
\end{itemize}
